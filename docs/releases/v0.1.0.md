# humane-ts v0.1.0

## Initial release

File sizes that read exactly the way macOS Finder shows them, and relative
dates in Rails ActionView's wording, for TypeScript and JavaScript. No
dependencies.

```ts
import { humanSize, timeAgo, distanceInTime } from 'humane-ts'

humanSize(4_132_383)                                 // "4.1 MB"
timeAgo(new Date(Date.now() - 180_000))              // "3 minutes ago"
distanceInTime(new Date(Date.now() + 180_000), new Date()) // "in 3 minutes"
```

- `humanSize` follows Foundation's `ByteCountFormatter`: fixed decimal places
  per unit (KB 0, MB 1, GB and above 2), rounding up into the next unit, and
  `"Zero KB"`/`"1 byte"`, all checked against real Finder output.
- `distanceInTime` and `timeAgo` use ActionView's `distance_of_time_in_words`
  wording, pick `"ago"` or `"in"` automatically, and take `approximate`,
  `includeSeconds` and `whenNil` options.
